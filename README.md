# GoF Design Patterns for Low-Level Design (LLD) - Classroom Edition

All 23 Gang-of-Four patterns as small, runnable Python files (stdlib only, 20-30 lines each).
Every file has: intent, when to use, and a student **Exercise**; `demo()` runs with assertions.

```
python run_all.py            # run everything
python run_all.py observer   # run one
```
